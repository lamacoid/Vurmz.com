# VURMZ Brand Binder

The source of truth for the VURMZ identity. Read the layer you need before touching design, copy, or assets. Plain language, no em-dashes, no hype (see 02 Verbal).

2. [Verbal](02-VERBAL.md) — pillars (Local. Thoughtful. Fast.), taglines, banned words, grammar, casing.
3. [Color](03-COLOR.md) — palette, roles, ratio, the dual light/dark scheme, paper texture.
4. [Type](04-TYPE.md) — Fraunces (display), Inter (body), Kerf (house engraving font), scale.

6. [Motif and surface](06-MOTIF.md) — the laser-framing cursor, the puffy lift, backlit teal, vignette, motion.
7. [Imagery](07-IMAGERY.md) — real work only, never stock; hero teal film; design library rules.
8. [Layout](08-LAYOUT.md) — grid, widths, section rhythm, components, radius, spacing.
9. [Applications](09-APPLICATIONS.md) — favicon, OG, social, business card, email, GBP. Production list.
10. [Tokens (code)](10-TOKENS.md) — the CSS design tokens that make it real. Use tokens, not hex.

## The short version
VURMZ is a one-person laser engraving shop in south Denver. It helps local businesses, fast and thoughtfully, and it is all Zach, no outside influence. The look is paper with teal ink (light) that flips to glassy teal (dark), warm and precise, with a laser-red spark. The voice is plain, first person, concise like a nice restaurant menu. Pillars: Local. Thoughtful. Fast.
